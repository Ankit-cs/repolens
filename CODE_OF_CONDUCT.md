# Code of Conduct

## Our Standard

RepoLens is an open-source project built around collaboration, learning, and constructive technical discussion.

I want the project to be welcoming to developers of different backgrounds, skill levels, and experience.

Contributors and community members are expected to:

* Be respectful, professional, and constructive.
* Discuss technical decisions in good faith.
* Provide clear and useful feedback.
* Critique code, designs, and ideas rather than individuals.
* Respect different perspectives, backgrounds, and experience levels.
* Keep discussions focused on improving the project.
* Accept reasonable differences of opinion.

Disagreements are normal in open-source development. They should be handled through respectful technical discussion rather than personal conflict.

## Unacceptable Behavior

The following behavior is not acceptable within RepoLens community spaces:

* Harassment or personal attacks.
* Discrimination or hateful conduct.
* Threats or intimidation.
* Deliberate disruption of discussions or project workflows.
* Trolling or repeated bad-faith participation.
* Publishing private or sensitive information without permission.
* Any other conduct that would reasonably make the project unsafe or hostile for others.

## Reporting

If you experience or observe unacceptable behavior, please contact the RepoLens maintainer through the contact information available on the repository profile.

When reporting an incident, please provide enough information to understand what happened, including relevant links, screenshots, or discussion context where appropriate.

Reports will be reviewed and handled as privately as reasonably possible.

## Maintainer Responsibility

The project maintainer may take appropriate action when this Code of Conduct is violated.

Depending on the situation, actions may include:

* Requesting that a participant stop inappropriate behavior.
* Removing inappropriate comments or content.
* Closing issues, discussions, or pull requests.
* Temporarily restricting participation.
* Removing participation privileges when necessary.

Actions will be based on the circumstances and the impact on the project community.

## Scope

This Code of Conduct applies to RepoLens project spaces, including:

* GitHub issues
* Pull requests
* GitHub Discussions
* Code reviews
* Repository contributions
* Project-maintained communication channels
* Other spaces where participants are representing the RepoLens project

## Questions

If you are unsure whether a particular situation falls within this Code of Conduct, use your best judgment and prioritize respectful, constructive communication.

Thank you for helping make RepoLens a welcoming and useful open-source project.
